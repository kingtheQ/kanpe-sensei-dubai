## 今回（11/18）タスク033でやったこと（つづりの点滅）
- 原因：世界マップ（world/）の `.star`（きらめきの点：2px四方・明滅アニメ）と、Star Alliance 券のクラス名 `star` が衝突。券が高さ2pxに潰れ、文字が重なって点滅していた（oneworld 券は無事）。同じく `.top`（世界マップの上の帯）が、ちぎるときの `top` と衝突していた。
- 直し：券のクラスを `tp-ow` / `tp-star` / `tp-sep`、ちぎる動きを `tp-top` `tp-bot` `tp-fall` `tp-shake` に変更（`tour-src/trip.js`）。数えの表示：上は `Landed 0 / 13`、券の角は `FLIGHT 1 / 13`。
- 大きさの基準：大人のNPCはキングの約1.1倍（`tour-src/art.js` の ART。pxは小数可、ナイロビ 9.75、ホテルのフロント 19.5＋置き場 top 217）。031 のNPCはこのリポジトリに見当たらず、いまある新しい絵の場面（ナイロビ到着・ドーハのホテルのフロント）だけを合わせた。
- 確認：`python3 tour-src/tests/test_bundle033.py`
