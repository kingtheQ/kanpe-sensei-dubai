# 世界一周編 イベント素材集（実在の出来事と体験談）

作成: 2026-11-12

## この素材集の使い方

世界一周編のイベントに使う「実際にあった出来事」を、空港ごとに20件以上ずつ集める素材集です。候補は絞らず並べ、キングが使いながら消していきます。

- **範囲(2026-11-12 キング決定)**: 30〜40空港を目安に、アジア・中東・欧州・アフリカ・北米・南米・南西太平洋の全域。上限15は1回の旅の上限で、調べる数の上限ではない。
- **順番**: 最初に「oneworld またはスターアライアンスで行けるか」の表を作り、行けない空港は理由を付けて分ける。そのあと地域ごとに出来事を足していく。
- **確認レベル**: **A**=公式 / **B**=高信頼(大手メディア・旅行会社) / **C**=体験談・口コミ / **D**=未確認。
- **日付**: 各行に情報源の公開日を付ける。確認日は特記がなければ 2026-11-12。公開から2年以上たつものは「古い」と書く。
- **書き方**: 体験談は要点だけ。個人名は入れない。分からないことは「確認できません」と書く。
- **進み具合**: この節の最後に、集めた件数・空港数・確認レベル別の数を書く(作業中は途中の数)。

**途中の数(2026-11-14 2周目のリサーチをしめた時点)**: 出来事524件 / 20空港(シンガポール23・バンコク24・香港24・ナイロビ26・アディスアベバ26・ヨハネスブルグ27・ヘルシンキ27・リマ25・カイロ26・アンマン27・カサブランカ25・マスカット26・ロンドン27・フランクフルト25・パリ25・アムステルダム25・ローマ28・チューリッヒ28・リスボン29・アテネ31) / 20か国・地域。確認レベル別は A=72、B=162、C=290、D=0。ほかに「達人賢者のアドバイス集」81件と「船の世界一周との比べ」の節があります。行ける・行けないの表は51空港+行けない候補5つ。リサーチはここで一度しめ、ゲームの組み立てに入ります。3周目の15空港と4周目の8空港は、作る順が近づいたら調べます。機種・一時帰国・ラウンジ・会話の種・最後の点検の各節も、そのときに足します。

**調べ方の注意(未確認の範囲)**: 出典は検索結果に表示された内容で確認していて、各ページの全文は読んでいません。金額・罰金・営業時間は変わるので、ゲームに実際の数字を出す前に公式ページで確かめてください。

## 行ける空港・行けない空港(oneworld / スターアライアンス)

候補51空港は、どちらかの連合の世界一周航空券で行けます。行けない候補は5つで、理由は「どの連合にも入っていない航空会社しか飛んでいない」です。

読み方: ◎=その空港を拠点にする加盟航空会社がある / ○=加盟航空会社が乗り入れている(拠点ではない)。◎は加盟一覧で確認(B)。○は一般的な路線知識で、2026-11-12時点の時刻表は未確認(D)。

加盟の最新状況(B): oneworld は15社(ハワイアン航空が2026-04-22に加盟、フィジー・エアウェイズ2025-04、オマーン・エア2025-06)。スターは26社(ITAエアウェイズが2026-04-01に加盟、アシアナ航空は2026-12-16に脱退予定)。LATAMは2020-05に oneworld を脱退し、南米に oneworld の拠点航空会社はありません。出典: [oneworld加盟一覧(2026-10-22確認)](https://awardtravelfinder.com/alliances/oneworld-airlines) / [スター加盟一覧(2026-10-22確認)](https://awardtravelfinder.com/alliances/star-alliance-airlines) / [2026年の移籍3社](https://www.insideflyer.com/posts/three-airlines-shift-alliances-in-2026/) / [LATAM脱退(2020-02-01)](https://www.executivetraveller.com/news/latam-to-leave-the-oneworld-alliance)

## 船の世界一周との比べ(続編の候補地)
