## 依頼内容

ナイロビ（ケニア）に到着したときに表示する「到着の1枚画面」の文案を作ってください。

画面の構成（決まっていること）：
- 国旗とその国の色が主役
- ケニアの雰囲気を捉えた、少しふざけた一言（日本語でよい。統計や社会データは使わない）
- 現地の挨拶を1つ（例：Jambo）

作ってほしいもの：
- 「ふざけた一言」の候補を5つ。各30字以内。ケニアのイメージ（サファリ、赤土、コーヒー、長距離ランナー、空港の空気など）から、雰囲気が伝わるもの
- 挨拶の候補は Jambo を基本に、ほかに自然なものがあれば最大2つまで追加可

## 出力形式（この型でだけ返すこと）

```

4.
```

## 禁止事項

- 統計・社会的なデータ（貧富の割合、治安の数字など）を一言に入れない
- 英語の勉強っぽい説明文を入れない
- コードは書かない
