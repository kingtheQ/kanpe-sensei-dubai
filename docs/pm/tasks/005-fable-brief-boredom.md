# Fable依頼文3：「飽きてきた」対策の設計

この文をそのまま Claude（Fable）に渡す。期限：火曜0:00 のリセット前。
版：v1.0（2026-11-15、PM作成）

---

あなたは英語学習ゲーム「カンペ先生／空港えいご物語」（世界一周編）の設計担当です。今回は「飽きてきた」問題への対策設計をお願いします。

## 最初に読むもの

1. リポジトリの docs/rules.md、docs/handover.md（「飽きてきた」が未決定事項として挙がっている）
2. docs/world-tour-design.md
3. docs/materials/event-materials.md（イベント素材集：20空港・524件の出来事）
4. tour-src/data.py の全場面（ナイロビ24シーン、ドーハ8シーン）

## 背景と問題

- 作成者がナイロビ→ドーハまで遊んだ感想：「飽きてきた」。どの国も入国審査・手荷物受け取りなど同じ場面が続き、文章も似てしまう。場面の割合の目標は空港5割・市内5割だが、現状は空港内でもスタッフとの定型会話が8割以上。
- このゲームの一番の原則：勉強している感覚に陥らせない。作成者は色々な英語アプリを試して全部飽きてやめた経験から、このゲームを作っている。
- 効くと分かっている要素：突然のイベント（歩いていて突然音楽が変わり、何かが起こる。ドキドキする瞬間）、物語の中での繰り返し（前に自分が言ったフレーズが、後の場面で相手の質問として返ってくる）。

## やってほしいこと（成果物3点）

1. **現状分析**：data.py の全場面を棚卸しし、「どの場面が・どう繰り返されているか」「退屈さの発生源はどこか」を具体的に挙げる。
2. **対策案**：複数案（最低3案）＋推奨案1つ。各案に「何を変えるか／素材集の524件をどう使うか／実装の重さ（軽い・中・重い）／勉強感が出ない理由」を付ける。観点の例：突然のイベントの配置設計、場面のバリエーションの作り方、物語的な繰り返しの組み込み、空港ごとの空気感の差し替え（音・看板・規模・色）。
3. **具体的な適用例**：推奨案をナイロビ→ドーハの区間に当てはめた例。どの場面の間に何が起こるか、時系列で示す。

## 守ること

- イベントの発火確率などの数値は未決定事項。勝手に決めず、案として幅を持たせて書く（例：「1空港に1〜2回程度」）。
- NPCに近づいてタップして話を聞いて回る方式は提案しない。イベントはプレイヤーの方に来る形だけ。
- 「復習」という言葉・画面につながる提案はしない。繰り返しは物語の出来事として設計する。
- 既存の英語アプリの型（並べ替えドリル、英単語→日本語3択クイズの復活など）は持ち込まない。
- イベント素材を使うときは、素材集の確認レベル（A〜D）に注意し、レベルの低い素材を事実として扱わない。
- 成果物は「設計案」であり、決定ではない。
