# 046 荷物受け取りの会話文の本組み込み：実装報告（v1）

2026-11-20。PM決定（案A）どおり、045の下書きを既存の荷物受け取り（`nbo_bag1`）の**置き換え**として組み込みました。

## 1. やったこと
- **会話文**：`tour-src/data.py` の `nbo_bag1` を、045の下書き（同じ便の旅行者と5往復）に差し替え。**場面の id は `nbo_bag1` のまま**にした（下書きの `nbo_bag0` にすると、trip.js の割り当て表・場所の定義・セーブのキー・雨もりの種の指定が全部ずれるため。PM決定の「trip.js に触らない」と合う）。場面の総数は変わらず、`trip.js` `build.py` の場所の並びも無変更。入国審査 → 荷物受取（`nbo_bag1`→`nbo_bag2`）→ SIM → タクシーの順も同じ。単語は belt / suitcase / tag / heavy / help（発音記号は辞書から全部引けた：missing IPA なし）。
- **雨もりとのつながり**（`tour-src/event_data.py` の VARIANTS）：従来は `nbo_bag1` の最後の台詞を「雨でベルトが止まっていたのでおくれた」に差し替えていた。新しい会話は「見つけて取る」ので、**1行目**を差し替える形にした：雨もりを遊んだあとは、旅行者が "Excuse me. The belt stopped for a while because of the rain. Is this the belt for the flight from Tokyo?" と聞く（キングの返事は元のまま）。雨もりの出来事そのもの（`nbo_ev_b_leak`）、置き場（入るとき・飽きサイン）、ベルト停止の描写は無変更。
- **旅行者の声と見た目**（`tour-src/build.py` の `SP.traveler`）：声 pitch=1.0。見た目はドーハのリュックの旅行者（`d_metrop`）と同じ系統（青い上着・黒髪・リュック）。ほかの声は 係員 1.1／雨もりの旅行者 0.95／売店・タクシー・係官 0.9〜1.15／ルル 1.35 で、1.0 と同じものはない。
- **専用スーツケース**：素材 `nairobi-baggage-hero-bag.png`（手前用 66×88・奥用 46×66）から、荷物スプライト（`tour/assets/art/nairobi-baggage-bags.png`）の**2行目（紺のソフトケース）を青＋黄タグに差し替え**。13段階の大きさは、手前＝素材の手前用そのまま、奥＝素材の奥用（暗さ0.85）、間は手前用を拡縮（暗さは045と同じ式）。作り方は `tour-src/art/prep_hero_bag.py`。
- **ベルトでの動き**（`tour-src/art.js` の `artHeroTh`）：専用スーツケースは、ほかの荷物と同じ向き・同じ速さでベルトをまわる。会話の3番目（"The blue one, next to the green board."）が始まったら、なめらかに**緑の板の右どなり**へ寄り、その台詞のあいだはゆっくり進んで板のとなりにとどまる。4番目（重いですよ）のあいだもベルトの上。5番目（取れました！のあと）と、荷物を受け取ったあとの場面（`nbo_bag2`）ではベルトから消える（荷物5個）。雨もりの出来事では、ほかの荷物と同じく止まる。会話の進み方（何番目の台詞か）にだけ合わせ、時計にはよらない。専用スーツケース以外の5個は045のまま（式どおり）。
