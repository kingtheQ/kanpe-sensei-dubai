## 2. 地図・タブ・クリアの印
- 出発：5か所（カウンター・出国審査 → 南の広場 → 空港の列車 → 北の広場 → ゲート・機内）。2つの広場と列車の線を地図に描いた。順番に解放（既存の仕組み）。ゲートは ▶ の選択（Gate desk／Board the plane）。
- 市内：6か所（スークの路地 → ホテル → スークの店 → レストラン → ホテルの朝 → コルニーシュ）。湾の弧を地図に描いた。自由に回れる（ドバイの街と同じ）。
- 場面の順：`seq` の場所は台本の順に出す（道をきく→お茶→ルルがいない、チェックイン→出国 など）。
- タクシー／メトロの場面のあと、市内のタブに切り替わる。機内の会話を終えると doha にクリアの印をつけて世界マップへ。
- 地図に戻ったときの曲を、そのモードの曲に直した（これまで到着でもドバイの曲になっていた）。市内の曲を1つ追加。

## 3. 014 と合わなかった所
1. **割りこみ#1（祈りの呼びかけ・音だけ）**：014 の部品は会話がないと動かない。ルルとの1往復（"Can you hear that? It is the call to prayer."）にした。専用の音は未作成。
2. **割りこみ#3（ルルがいなくなる）**：014 の枠でなく、ふつうの5往復の場面（doh_city_t3）として実装。そのため、ふつうの場面でも lvis／nohelp を使えるよう build.py を1か所広げた。
3. **持ち越し#5（「最初の寄港地」）**：相手がキングの言葉を返す形が作りにくく、学生が「ドーハが最初？」ときき、キングが「最初はナイロビ」と答える形にした。
4. **ゲートの割りこみの順**：顔なじみ（k）と放送（i）が同じ入口にある。k が先、そのあとサインが出れば i。
5. 場面のIDは `doh_` で始まる必要があるため、018 の案（dep_／city_）に `doh_` をつけた。
