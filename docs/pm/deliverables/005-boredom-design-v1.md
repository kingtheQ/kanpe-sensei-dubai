## 0. 結論（先に）

1. **退屈の一番の原因は「場面が似ている」ことより「次に何が起きるか全部わかる」こと。** 37場面すべてが、相手が先に話す→キングが答える→ちょうど5往復→お礼で終わる、の同じ形。場面と場面の間には何も起きない。
2. **ドーハの到着は、ナイロビの到着と同じ4か所・同じ順・同じ位置・同じアイコン。** 絵と曲は別だが、地図の骨組みが同じなので「また同じ」に見える。
3. **推す案は「旅はつながっている」案。** 中身は3つ：①割りこみ（突然の出来事が向こうから来る）②持ち越し（前に言ったことが、あとで相手の口から返ってくる）③顔なじみ（同じ旅人に、空港をまたいで何度も会う）。
4. **ナイロビ→ドーハは、5往復の新しい場面を1本も足さずに変えられる。** 足すのは、割りこみの置き場7つ、1〜2往復の「ひとこと場面」4つ、既存の台本の1行差し替え2か所。
5. **いまの台本には、すでに「持ち越し」の種が5つある。** ただし全部キングが同じことをもう一度言うだけで、相手から返ってくる形は0。ここを直すのが一番安い。
6. **素材集524件は「何が起きるか」には使えるが、「誰と話すか」は足りない。** 会話の相手は上位30種すべてが係員・店員・運転手の側。旅行者は入っていない。旅行者は配役で作る。
7. **ドーハは素材集に節がない（0件）。** 今回、適用例に使う3点だけ調べて出典を付けた（第4章）。
8. **台本に食いちがいが4つあった**（スーツケースの色など）。持ち越しを入れると目立つので、先に直す対象として挙げた（1-5）。

### 1-3. 退屈さの発生源（強い順）

1. **先が全部読める。** 場所を選ぶ→5往復→Word Battle→Meaning、が37回同じリズムで続く。場面の長さも結末（お礼→送り出し）も毎回同じ。
2. **場面の間に何も起きない。** 地図は「次の会話を選ぶメニュー」になっていて、歩いている間のドキドキがない。
3. **国が変わっても骨組みが同じ。** 1-2の地図の表のとおり。
4. **キングがずっと受け身。** 先に話さない。困っても相手が直してくれる。失うものも、間に合わないこともない。
5. **相手が制服の人ばかり（91%）。** 係員は質問して送り出すのが仕事なので、文がどうしても似る。
6. **何も持ち越されない。** 言ったこと・買ったもの・会った人が、次の場面に影響しない。場面どうしがつながっていないので、「旅」でなく「問題集」に見える。
7. （範囲外だが重なっている）毎場面の後の Word Battle と Meaning が、勉強の区切りのリズムを作っている。廃止の方向は決定ログにあるので、ここでは扱わない。

## 2. 成果物2：対策案（6案）

候補は絞らずに並べた。重さの意味：**軽い**＝台本（data.py）だけ／**中**＝エンジンに小さな仕組みを1つ足す／**重い**＝地図や画面の作りかえ。
エンジンは dubai/index.html を元に build.py が差し替えて作っているので、「中」以上はドバイ編の元ファイルに手が入る（第5章の確認10）。

### 素材の確認レベルの扱い（全案共通の決まりの案）

| レベル | 使い方 |
|---|---|
| A・B | 出来事の筋に使ってよい。ただし「いつも起きる」とは言わせない。公開から2年以上のものは「前にあった話」として扱う |
| C | 事実として言わせない。使い道は3つだけ：①旅行者のうわさ話（I heard ...）②ルルのメモ ③演出のヒント（金額・時間・罰金の数字は出さない） |
| 数字 | 金額・時刻・番号は架空にするか、作る直前に公式で確認する（既存の決まりどおり） |

### 案A：割りこみ（突然の出来事が向こうから来る）

| 項目 | 内容 |
|---|---|
| 何を変えるか | 場面と場面の間（地図で次の場所へ向かう途中）と、場面の入口に、出来事を差しこむ。形は1つに固定：**①曲が止まる・変わる → ②出来事が来る（アナウンス／声をかけられる／ルルに何か起きる／空港そのものの異変）→ ③英文2〜3個の▶から選んで声に出す → ④世界が反応して元の曲に戻る**。選択肢に「はずれ」は作らず、どれを選んでも話が別の向きに進む |
| 出来事の種類 | アナウンス（ゲート変更・遅れ）／声をかけられる（落としもの・道を聞かれる・席を聞かれる）／ルル（いなくなる・声が出ない・勝手に買ってくる）／空港の異変（停電・雨漏り・スト・列が止まる） |
| 素材集の使い方 | 空港の異変とアナウンスの筋に、欠航54・遅延34・行き先変更15・ターミナル移動10・停電4 を使う。各空港の節の冒頭にある「その空港らしい出来事3つ」を、その空港の割りこみの第一候補にする。A・B は筋に、C はうわさ話に |
| 起きる回数 | 未決定。置き場は多めに用意し、実際に起きるのはそのうち一部にする（例：1空港に1〜2回程度、続けては起こさない）。何をきっかけに起こすか（決まった場所／偶然／同じ型が続いたとき）も未決定 |
| 重さ | 中。▶で英文を選ぶ見た目（二重枠）と、選んだ文を言う画面はすでにある。足すのは「場面の外で起こす仕組み」と「曲の切りかえ」。出来事1つあたりの台本は1〜3往復 |
| 勉強感が出ない理由 | 出来事には「問題」がなく、「間に合うか・通じるか」だけがある。知っている文で切り抜けるので、新しく覚える感じがしない。いつ来るか分からないので、地図を歩く時間に意味が出る |
| 弱い所 | 多すぎると疲れる。国が変わっても形を変えない決まりがあるので、型は1つに固定して中身で差を出す |

### 案B：持ち越し（言ったことが、あとで相手の口から返ってくる）

| 項目 | 内容 |
|---|---|
| 何を変えるか | キングが言ったこと・選んだこと・持ち物を「旅のメモ」（端末の中）に残し、あとの場面の相手のセリフに差しこむ。例：入国で For three days. → 出国で Did you enjoy your three days? ／保安検査の木のキリン → 次の国の税関でまた止められる。段階は2つ：**B1＝文を固定で書く（台本だけ）**、**B2＝選んだ答えで文が変わる** |
| 素材集の使い方 | 「あとで聞かれる」型の素材を返しの場面にする：入国68（出国・次の国の入国で同じ問いが来る）、税関12、荷物16、保安検査15。ナイロビのレジ袋（#13〜15、C）は、布の袋を次の国の店員にほめられる、のように演出として使い、規則の説明はさせない |
| 起きる回数 | 未決定。目安は「1場面に0〜1個」。全部の場面に入れると仕掛けが見える |
| 重さ | B1は軽い（1行の差し替え）。B2は中（言った内容の保存と、台本への差しこみ） |
| 勉強感が出ない理由 | 同じ文にもう一度出会うが、理由は「さっきの話の続き」。本人は「覚えていてくれた」「またキリンか」としか感じない。「復習」の画面も言葉も出ない |
| 弱い所 | 2本のうち1本でクリアできるので、種の場面を遊んでいないことがある。「言った場合だけ返る」作りにする。台本の食いちがい（1-5）を先に直す必要がある |

### 案C：空港の顔（到着の骨組みを空港ごとに崩す）

| 項目 | 内容 |
|---|---|
| 何を変えるか | 「入国審査→手荷物→SIM→タクシー」の4点セットをやめ、空港ごとに「その空港にしかない1か所」を足し、「なくてよい1か所」を引く。場所の数と位置で規模を出す（大きい空港は場所が多く遠い）。看板は現地語＋英語の2段、最初の数秒の音、床と壁の色を空港ごとに差しかえる |
| 例 | ドーハ：空港の中の列車が入国審査の前に入る／とても静か。ナイロビ：ターミナルの間は屋根のない通路。ヘルシンキ：自動ゲートで審査官と話さない→そのかわり電車の検札が来る |
| 素材集の使い方 | 各空港の節の冒頭文（らしい出来事3つ）と、種類「ターミナル移動10・乗り継ぎ72・交通99」から、その空港だけの場所を1つ選ぶ。施設の場所は A・B のものを使い、C は作る直前に確かめ直す |
| 重さ | 中〜重い。地図の場所の定義と背景の絵が空港ごとに要る。SIMのように毎回同じになる場所を引くだけなら軽い |
| 勉強感が出ない理由 | 着いた瞬間に「ここは前とちがう」と分かる。旅行前のリハーサルにもなる（実際に行ったとき「ゲームで見た」） |
| 弱い所 | 手間が大きい。51空港すべてでやると重いので、「1空港に1か所だけ変える」を下限にする案 |

| 項目 | 内容 |
|---|---|
| 何を変えるか | 同じ場所・同じ出来事で、相手を旅行者にする。さらに**キングが先に話す場面**と**キングが助ける側の場面**を作る（道を教える、席をゆずる、荷物を見ていてと頼まれる）。場所ごとの2本を「係員1本＋旅行者1本」にそろえる |

| 項目 | 内容 |

### 推奨案：「旅はつながっている」（A＋B＋F を軸に、Dを台本の原則に）

- **割りこみ（A）で「先が読める」を壊し、持ち越し（B）と顔なじみ（F）で場面どうしをつなぐ。** 配役（D）は新しい仕組みでなく、これから書く台本の原則として入れる。
- 推す理由：発生源の1・2・4・5・6に届く。重い作りかえがない。いまの台本の種（1-4）と doh_bag2 をそのまま生かせる。効くと分かっている2つ（突然のイベント、物語の中のくり返し）がそのまま柱になる。
- 入れる順（軽い順）：
  1. **台本だけ**：食いちがい4つを直す／持ち越しB1（1行差し替え）／顔なじみを既存の場面に置く／「ひとこと場面」（1〜2往復）を足して場面の長さをばらす。
  2. **仕組み1つ**：割りこみの型（曲の切りかえ＋▶で選んで言う）。最初の1つはゲート変更のアナウンス。
  3. **仕組みもう1つ**：旅のメモ（B2）と、ルルがいない回。
- 案Cは、ドーハ到着に列車を1か所足す所だけ試す（地図が変わるので確認7）。案Eは、ゲートをまちがえて走る小さい版だけを割りこみの中に入れ、乗りおくれの本編は後に回す。

## 6. 最後の点検

- お金の損失：課金・有料のAPIは使わない案。該当なし。
