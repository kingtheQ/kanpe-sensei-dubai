# タスク041 完了報告：チケット売り場（旅行代理店）の背景と地図アニメ

## 適用した場面
- 窓口の全場面（bg が tdesk か rtmap の場面。判定は `artIdFor`＝build.py）：同意の1枚（win_consent）・宣言（win_decl）・聞き取り5本（win_c1/c2/c5/c7/c8）・線を引く（win_route）・おすすめ（win_rec）・値段3通り（win_price_*）・読み上げ確認3通り（win_rb_*）・名前の確認（win_name）・搭乗券（ticket_star / ticket_ow）
- 対象外（変更なし）：賢者の広間、ナイロビ・ドーハの各場面

## 説明アニメを付けた会話
- win_route（「線を引く」3往復）だけ。会話の進みに合わせて、1往復目で羽田→ナイロビ、2往復目でロヴァニエミ→クスコ→ホノルル→羽田、3往復目で「もどる線は止まる」（青い点線と✕）
- ほかの窓口の会話は、航路なしの地図のまま

## 作ったもの
- 背景 `ticket-office-bg-clean-noroute.png`（1536×960）を 028 のフルブリード（#sceneA）で表示
- 係員：カウンターの向こう中央（x=768）。室内の大人の高さ 273px（ホテルのフロント係と同じ基準）に縮め、カウンターの高さ（y=596）で切って下は隠す
- ルル（左 x=699）・キング（右 x=835）：絨毯の上（足もと y=920）に後ろ姿。素材のまま（キング136×229、ルル131×205＝室内の基準）。すき間は約3px
- 人の動き（037）：足と影は固定、腰より上だけ 3px ぶん上へ伸び縮み（係員 0.8回/秒、ルル・キング 1.1回/秒）
- 航路の描き方：都市の位置と曲線（2次ベジェ）をコードで計算し、15px おきに点線（+印）。区間ごとに 1.1 秒。小さい飛行機（コードで描くドット）が先頭を飛び、着いた都市の印が光る（光の輪がまたたく）。ホノルル→羽田は地図の左はしから出て右はしに入る西まわり
- 静止画フォールバック：航路の描画で例外が出たら、その場面は航路入りの `ticket-office-bg-clean.png` に切りかえる。アニメは時間だけで動き、会話の進行は待たない
- 台本・判定・保存形式：変更なし

## 実測（ヘッドレスChrome・1536×960のキャンバスを直接読んだ値）
- 窓口の全16場面＋同意の1枚：新しい絵で表示、JSエラー 0
- 足もと・影（キング・ルル）：24回中 変化 1種（＝動かない）／キングの上半身は 2種／係員のカウンター際は 1種・頭は 2種
- 航路の画素（地図の上側、0.3秒→1.3秒→4.8秒）：1往復目 924→1452→2004、2往復目 2004→2301→5363。3往復目は 5221→5005→5021（引く線はなく、青い点線と✕）
- 描けないとき（描画を強制的に失敗させた）：地図が航路入りの静止画と一致（差 0.0000）、会話は次へ進む
- 既存：test_routes（エラー 0）、test_bundle033（star・ow とも OK）。新規：`tour-src/tests/test_ticket041.py`（全項目OK）
