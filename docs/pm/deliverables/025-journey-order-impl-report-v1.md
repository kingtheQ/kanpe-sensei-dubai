# 025 旅の順番の直し — 完了報告（2026-11-17）

決定（キング 2026-11-17）：賢者 → 窓口で世界一周チケットを買う → 飛行機に乗る → 到着。

## 変えたこと（コミット3つ）
1. 搭乗の条件（world/index.html）
   - タイトルの「はじめから」は、世界マップでなく賢者の広間（`../tour/`）へ送る。記録を消した直後も同じ。
   - ゲートで tour 行き（ナイロビ・ドーハ）に飛ぶには、`kanpe-tour-save-v1` の ticket が要る。ない場合は飛ばさず、ゲートの係員が「You need a ticket first. Please see the sage. / チケットが まだ ありません。賢者の ところへ 行こう。」と案内し、▶ 賢者の ところへ で広間へ戻す。グアム行きは変えていない。
2. 購入後の位置（tour-src/build.py, window.js → tour/ を再生成）
   - 券を買った直後の `worldAt('nairobi')` と、ナイロビ読み込み時の `worldAt` をやめた。買い終えたら `../world/?map=1`（羽田のマップ）へ戻る。着陸して初めて到着場面が始まる。新しい保存キーは増やしていない。
3. 導線（world/index.html）
   - 世界マップに「タイトルに もどる」を追加。押すと、タイトルの選択（はじめから／つづきから）が開く。「はじめから」→確認文（タスク022のまま）→「はい」で、世界マップ＋世界一周編の記録を消し、メモ・声の記録は残す。30分のタイトル省略も外す。
- 機内の文言「着くと、到着場面から はじまります。」は変更なし。新しい順番では、券を持って飛ぶ初回の着陸が到着場面から始まるので、文言と実際が合う。

## 確認（ヘッドレス、tour-src/tests/flow025/scenario.py）
- 初回：はじめから → `/tour/`（広間「達人賢者の広間」）→ 賢者 → 窓口 → 購入 → `/world/?map=1`（現在地 羽田、world.at 未更新、tour.ticket=star）→ 搭乗ゲート → 機内 → `/tour/#w=1` 「ナイロビに到着」。着陸後に広間・窓口は流れない（賢者タブなし）。ページエラー0。
- 券なしでゲート（ナイロビ行き）：飛行画面にならず、案内表示、ボタンで `/tour/`。グアム行きは従来どおり飛行画面。
- 記録消去：30分以内でもマップから「タイトルに もどる」→はじめから→はい。world・tour の記録は消え、メモ・声は残る。→ `/tour/`。
