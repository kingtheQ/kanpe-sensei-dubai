| 指示 | 実装 | 確認 |

| 1 店員が英語で話す | 台本の流れ：注文 → 氷とケーキ → ケーキの種類 → 「That is eight hundred shillings. How would you like to pay?」 → 「Here you go. Enjoy!」 | A3 |
| 2 選択は1場面に1回、日本語の短い単語カード | 支払いの1か所だけ。カード＝`💳 カード払い`／`💵 現金`／`📱 M-Pesa`。英語の▶選択肢は出ない。読み上げない | A1・A1b・A2 |
| 3 M-Pesa は店員に聞いてから | M-Pesa をタップ → 見本の音声（What is M-Pesa?）→ カンペ → 店員が短く説明（スマホの中のお金・ケニアでみんな使う）→「Yes, I will pay with M-Pesa.」→ 支払い | C1・C2・C3 |
| 4 タップしたら、見本の英語が音声だけ | `sample` 段階（🔊 のみ。文字なし）。声が使えなくても止まらない保険の時計つき | A4・A5b |
| 5 そのあとカンペ（文字）が出て声に出す | 既存のカンペ画面（自動で聞き始める） | A5 |

| 7 発音の数値は出さない | 「n/n語 ○○%」「7割未満」「Nice!」「Too short/long」をこの場面で出さない。通じたかは店員の反応（Okay./聞き返し/rep の一言）で返す | A7・D3 |
| 8 支払いの結果は目に見える形 | カウンターにカードリーダーが出て、選んだ方法（カードをかざす／お札を3枚置く／スマホをかざす）→ ✓ → アイスコーヒーとケーキのひと切れが出てくる。場面の終わりまで残る | A9・B1・C3、画面で確認 |

## クロが決めたこと（指示に書かれていなかった点。変えたいときは言ってください）
1. **「見本の音声だけ→カンペ」は、カードをタップした直後のカンペだけ**に適用（指示の4・5の文のとおり）。ふつうの返事（ラテなど）は今までどおりカンペが先に出る。M-Pesa の説明のあとの「Yes, I will pay with M-Pesa.」も、文字つきですぐ出る。
2. **前の版（053）の「ホットかアイスか」の分かれ目は、選択でなくした**（1場面に1回の決まりのため）。店員が「Would you like it iced? And a slice of cake with it?」とたずね、「Yes, iced, please.…」と言う流れ。その結果、**iced・slice の反応時間の計測はなくなった**（夢の台本には残っている。計測は shillings だけ）。ここを測り直したいなら、キングの判断が要る（発音の1回目で通ったかを使う案などがある）。
3. 日本語カードの「M-Pesa」は、日本語に直さず**名前のまま**。カードは3枚固定（順番も固定）。
4. 失敗が3回に達したときの「あとで強化合宿で練習する語」への記録（`noteWeak`）は今までどおり残した。
5. 音声認識が M-Pesa を1語（mpesa）に聞いた場合に備え、照合の辞書に `mpesa→m pesa` を足した（**実機で未確認**）。
6. カウンターの上の飾りのカップを、支払いの演出のあいだだけ隠している（見やすい大きさにするため）。
