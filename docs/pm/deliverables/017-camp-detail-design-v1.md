## 0. 結論（先に）

1. **B は「会話のあと、ルルが顔を寄せて、聞こえた言葉を見せ、口の形を1つだけゆっくり見せる」12秒。** 出す条件は「引っかかりがあった／直前から会話1本あいた／直前が大場面でない／空港で3回まで／スキップが続いたら休む」。決まり文句を使わず、ルルの声は3回（いまの合宿は55.6秒で24回）。
2. **C は「大場面の前に、ルルが先回りして段取りする」28秒（短い版20秒）。** 大場面は5つの目印のうち2つ以上を満たす場面。中身は 見通し→本番の文→口の形の準備（単語2語）→通し→送り出し。判定はしない。判定は本番でつく。
3. **口の形は「10形・21部品・絵37枚＋枠1」。** 唇7・歯4・舌6・合図4の部品を組み合わせて、16の音の違い（既存の13音＋004 の追加音）を出す。004 が「新しく要る」とした語尾のL・ɚ・短いイ・有声の語尾は、**形としては既存の組み替えで足りる**（新しい部品は0）。
4. **ジムとは合体できる。** ジムの鏡を「ルルの顔の窓」にして、口元を幅いっぱい（80×64ドット、390px幅で約4.9倍）に大きく見せる。ルルの顔の画面だから、場面画よりドットが粗くても筋が通る。
5. **スパルタ時間は、ホノルル4日のうち3日に1セット約70秒ずつ（計3分30秒）、休む日を1日。** ルルは「Coach Lulu」（案）に変身。ムチは動作・勢いに向け、能力は否定しない。3セットでムチ9：アメ12。判定はしない（判定は翌日の実戦＝レンタカー返却・最終日の一言）。
6. **成長の実感は「借金」を全部やめて3つの積み上がりに替える。** ①動かした回数（常時は見せず、節目だけルルが一言：25・50・75、仮）②通じた場面（写真がアルバムに増える。通じなくても笑える写真が増える）③聞こえた語の変化（ルルの耳の Before/After）。
7. **決定の間のずれが1つある。** 004-5「発音の結果はプレイ中は何も見せない」と、006-12「なんと聞こえたかをあからさまに表示する」。この文書は「見せるのは聞こえた言葉の事実だけ。点・％・順位・合否は見せない」と読んだ（PM確認：017-2）。
8. **増える時間は、空港1つあたり平均52秒・最大99.5秒（1空港30分以上の約3〜6％）。** 合宿を「行く場所」にしない代わりに、短いものを散らす。

- 「なんと聞こえたか」は、いまはブラウザの音声認識が返した文字。本人の音そのものではない。Azure の発音評価は試す決定（004-8）のまま未実施で、料金の追加分も未確認。この設計は、どちらの方式でも動く（語の単位で足りる）。

## 2. B　ルルのひとこと

### 2-1. いつ出るか

会話（5往復）が終わった直後、場面を出る前に出る。次の条件を**すべて**満たすとき。

| # | 条件 | 理由 |
|---|---|---|
| 1 | ルルがその場にいる（不在でない） | 世界の出来事と矛盾させない（バイブル §1・§10） |
| 2 | その会話に「引っかかり」が1つ以上ある（7割未満の文／ヘルプを使った文／鍛える音の語が聞き違えられた文） | 引っかかりがなければ出ない。出ない日がある |
| 3 | 直前の B・C から会話が1本以上あいている | 続けて出すと疲れる（006 の疲れの元） |
| 4 | 直前の会話が大場面でない | 大場面の余韻（相手の反応＝手ごたえ）を守る |
| 5 | その空港で3回未満 | 上限。条件3 と合わせると、会話6本なら実質3回まで |
| 6 | 直近の B をスキップ（タップで飛ばす）した回数が、連続2回未満 | 飽きサイン。2回続いたら、次の2会話は休む（005-3 と同じ考え方で、確率で決めない） |

出さない場面：アナウンスを聞いて選ぶ場面（口を使わない）、割りこみの出来事の直後（勢いを止めない）、ルルが不在の会話。
ルル不在から戻った直後の最初の B は、2-6 の8のように「電話越しに聞いていた」形にする（辻褄が合う）。

### 2-2. 何を拾うか（引っかかった音・文）

使うデータは今あるもの：期待文（カンペ）、聞こえた文、語ごとの一致、7割の結果、ヘルプ使用。

1. 期待文と聞こえた文を語の単位で比べ、違った語・抜けた語を出す（いまの集計と同じ判定）。
2. **聞き違いの表に載っている語は除く。** 機械の都合で責めない。
3. 各語に音タグを付け（辞書の音タグ／SND）、音ごとの点を出す。式は pickLessons と同じ（聞こえた語にその音がなければ×2）。診断の「音ごとの記録」ができたら、その順位で加点する（加点の数値は仮）。
4. 直近2回に出した音は後ろへ回す（続けて同じ音を出さない）。
5. **1つの会話で拾うのは、1音・1語・1かたまりだけ。**（004 規則3「主役は1つ」）
6. 語は、不一致の語のうち「次の場面で使いそうな語」、同点なら短い語を選ぶ。
7. ひとことで言う「かたまり」は、その語の前後2〜4語（例：my flight）。文全体は言わせない。

7割未満の文があった会話は、そのかたまりが「文の一部」になるので、ルルは文の短い版（5語まで）を1回だけ一緒に言う。やはり判定しない。

### 2-3. 1回の組み立て（12秒）

| # | 何をする | 秒 |
|---|---|---|
| 1 | ルルが顔を寄せる（顔の窓が場面の上に出る） | 0.8 |
| 2 | ルルの耳に聞こえた言葉を見せる＋ルルのひとこと | 3.5 |
| 3 | 口の形をゆっくり大げさに（用意→音→戻す→もう一度） | 4.0 |
| 4 | キングが口を動かす（1回） | 2.5 |
| 5 | ルルの締め | 1.2 |
| 計 | | 12.0 |

検算：0.8＋3.5＝4.3、＋4.0＝8.3、＋2.5＝10.8、＋1.2＝12.0。

| 版 | 計算 | 秒 |
|---|---|---|
| 短い版（同じ音が続く2回目。口の形を2.0秒に） | 12.0−2.0 | 10.0 |
| 標準 | | 12.0 |
| 初回の版（各形の初回だけ、日本語の口と並べて比べる＋2.0） | 12.0＋2.0 | 14.0 |
| 2回言う版 | 12.0＋2.5 | 14.5 |

初回の版は2回言う版にしない（上限15秒を超えるため）。
ルルの声は3回（ひとこと・お手本・締め）。キングが声を出すのは1〜2回。
いまの合宿との比較（006 の実測：失敗0回で55.6秒・ルルの声24回・キングの声9回）：時間は12.0÷55.6＝約22％、ルルの声は3÷24＝12.5％。

### 2-4. 「なんと聞こえたか」の見せ方

- 場所：ルルの頭の上に「耳」のマークと吹き出し。**日本語の文字は入れない。**
- 大きさ：英語を大きく（目安は本文の約2倍）。聞こえた文全体を1回見せる。
- 色：期待と違った語は**青**（赤は使わない。波線は使わない：rules §3）。抜けた語は青の枠だけの空欄にする。
- 言い方：ルルの耳が聞いた言葉であって、「あなたの発音」ではない。点・％・順位・合否・「できていない」の言葉は出さない。
- 例：キングが "I have one bag" と言い、"I have one back" と聞こえた → 吹き出しに大きく I have one **back**（backだけ青）。
- 保存：端末内に残し、後から記録帳で見返せる（6-6）。音声そのものは保存しない（文字だけ）。

### 2-5. 台詞のパターン（5型）

ルルは先生でなく、旅の連れ。**Listen. / Repeat after me. / Great! は使わない。** 同じ型を続けて出さない。同じ言い回しは10回以上あける（目安）。英語は短く、やさしく（1行15語まで）。

| 型 | 中身 | 向く場面 |
|---|---|---|
| P1 茶々 | 聞こえた言葉を、おかしな意味として拾う | 軽い会話・笑える聞き違い |
| P2 実利 | 次に使う相手が喜ぶ、と言って形を出す | 次の場面がはっきりしているとき |
| P3 ルルも失敗 | ルルの耳／ルルの口も同じ間違いをして、一緒に直す | 続けて引っかかったとき（ロボットの故障ギャグ） |
| P4 ほめ＋1つ | まず通じた所を1つ具体的に言い、そのあとで1つだけ足す | 結果がよかった会話のあと |
| P5 無言 | ルルは台詞なしで、顔を寄せて口だけ大げさにやる。キングが吹き出す | 同じ型が続いたあとの息抜き |

英語の台詞はあくまで例。実際の台本は、シーン状態シートを渡して台本担当（Gemini）に作らせる（DECISIONS の分担）。聞こえた語は例であって実データではない。

## 3. C　本番前の打ち合わせ

### 3-1. 大場面の決め方

次の5つのうち**2つ以上**を満たす場面を「大場面」とする。

| # | 目印 |
|---|---|
| ア | 1つの文が長い（8語以上）、または文を続けて言う |
| イ | 失敗のコストが物語で大きい（乗り遅れ・お金・予約） |
| ウ | ルルが助けられない、または助けにくい（電話越し・不在） |
| エ | 記録に残る（宣言・声の日記・最後の入国：004 の測り直しの場面） |
| オ | 国の最初か最後（入国審査・出国審査） |

当てはめた例（世界一周編・ドバイ編の既存の設計から）：

| 場面 | 満たす目印 | 大場面か |
|---|---|---|
| 入国審査 | オ・ア（滞在日数など） | ○ |
| ホテルのフロントでツアー予約（ドバイ） | イ・ア | ○ |
| レンタカーを返す電話（ホノルル） | ウ・イ・ア | ○ |
| 各国の出発ゲートの声の日記（004） | エ・ア | ○ |
| 最後の入国（羽田・成田） | エ・オ・ア | ○ |
| 出国審査（帰りの鏡） | オ・エ | ○ |
| 買い物の一言・食事の注文 | （どれも1つ以下） | × |

数は、空港1つにつき C は0〜2回（上限）。連続して出さない。

### 3-2. 20〜30秒の組み立て

| # | 何をする | 標準 | 短い版 |
|---|---|---|---|
| 1 | 見通し：次の相手の姿を、絵でルルが見せる（言葉でなく） | 3.0 | 3.0 |
| 2 | 本番の文：ルルがゆっくり言う（口の形つき、キングは聞くだけ） | 5.0 | 5.0 |
| 3 | 口の形の準備：その文の中の「鍛える音」の語を2つ。見せる2.0＋まねる2.0を2語（単語でよい） | 8.0 | 8.0 |
| 4 | 通し：ルルが相手役で最初の一言（2.0）＋キングが本番の文（4.0）＋間（2.0） | 8.0 | なし |
| 5 | 送り出し | 4.0 | 4.0 |
| 計 | | 28.0 | 20.0 |

ルルの声は6回（標準）。キングが声を出すのは3〜4回（語2＋通し1、言い直し1回で4）。短い版は2回。
文は、004 規則1（言い分け）で「鍛える音の語が多い方」を選ぶ。判定はしない。聞こえた語は記録する。

### 3-3. 型（4つ。直前と同じ型は出さない）

### 3-4. 例（3場面）

|---|---|---|---|

### 3-5. 本番のあと（手ごたえ）

- 本番（実戦）は、いまの「7割以上でOK」のまま。通れば相手の反応が変わる（笑う・ほめる）。これが手ごたえで、ルルは余計な評価を足さない。
- 通らなくても会話は止めない（rules §6）。ブッの音は実戦だけ（決定済み）。
- 結果は裏側で「その音を含む文が通じた／通じなかった」として記録し、6-5 の「段」を動かす。

## 4. 口の形の見せ方（006-2 の解決案）

### 4-1. 考え方

- ルルはロボットなので、**ルルの顔の画面に口元だけを映して、幅いっぱいに大きく見せる**。ドットが場面画より粗くても、顔の画面（ディスプレイ）の中の拡大だと説明がつく。
- 見るだけ・まねるだけ。**文字の説明は付けない**（rules §6 を「見てまねる」に寄せる提案は 9章 017-13）。
- 口の形の名前（かむ・べろ…）は設計用の名前。画面には出さない。

### 4-2. パーツの数え方

口は「4つの層」の部品を重ねて作る。形は部品の組み合わせ。**音が増えても、部品の組み替えで済めば追加は0。**

| 層 | 部品 | 数 |
|---|---|---|
| 唇 | L1 ゆるむ／L2 横にひく／L3 まるく出す／L4 ゆるい丸／L5 大あけ／L6 とじる／L7 下唇を内にかむ | 7 |
| 歯 | T1 上下そろう／T2 上の歯だけ見える／T3 上下にすきま／T4 見えにくい | 4 |

## 6. 成長の実感

### 6-1. 基準

006-8：**飽きないこと**と**ちゃんと成長してるって実感できること**。常設の数字は減らし、節目と写真と語の変化で実感を出す。画面に余計な情報を出したくない（2026-11-08）、プレイ中は結果を見せない（004-5）にも合わせる。

### 6-2. 借金から積み上がりへ

| いまの表示 | 置き換え案 | 理由 |
|---|---|---|
| マップのボタン「言えなかった単語 N語」（減らない） | 数字を出さない。入口は設定の記録帳の「ルルの耳」へ | 借金の数をやめる（006 §6-7 の続き） |
| 「0% 7わり未満」「✕」 | 聞こえた言葉だけ（違う語は青） | 事実だけ |
| 回数の箱「1・2」「2かい いってね」 | 数字を出さない。ルルのダンベルの上下とビートの拍で数える | ノルマ感を消す |
| 「いまの きみ ✕／めざす ◎」 | 廃止。口の形のお手本だけ | テストに見える |
| 「ことば 1/2」「ぶん 1/1」（分母あり） | 廃止 | 分母をなくす |

置き換え先は3つ：

1. **動かした回数。** 声を出したら自動で＋1（無声モードは「できた」で＋1）。画面には常設しない。記録帳で見られる。
2. **通じた場面。** 大場面で通じたらルルが写真を撮る（ドヤ顔）。通じなくても笑える写真が撮れる。アルバムは増えるだけで減らない（バイブル §5「失敗は別の物語」）。
3. **聞こえた語の変化。** 記録帳の「ルルの耳」で、同じ語の Before/After が並ぶ。ホノルルの終わりでも1語出す（5-7）。

### 6-3. 見せ方の規則

- 増える方向だけ。分母を作らない。下がる数字を見せない。
- 最初から「0」を見せない。
- 常設の数字を作らない。見るのは記録帳か節目の演出だけ。
- 点・％・順位・合否を出さない。

### 6-5. 音の「段」（重さを上げる）

追補（筋トレの考え方）の「負荷を上げる」を、5段にする。

| 段 | 重さ | 主に担当 |
|---|---|---|
| 1 | 音（口の形だけ） | B、スパルタ S1・S2 |

- 段を下げる合図：同じ音の語を含む文が、**3つの場面で続けて通らなかった**（仮）。下がったことは見せない。
