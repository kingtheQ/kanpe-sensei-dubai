## 4. 「飽きのサイン」：入口と、定義が必要な場所

作ったもの（`tour-src/build.py` の EVJS、tour に埋め込み）：
- セーブに `ev = {fired, streak, last}` を追加。場面が終わるたびに `evNote()` が「場面の型（通常／旅行者／出来事／ひとこと）」を受け取る。
- 枠ごとに「サインが必要か」を持つ（a〜g は必要、f1・f2 は固定で必要なし）。`evGate()` が「入口／おわり／場面」の3か所で枠をのぞく。
- 1枠は1セーブにつき1回だけ起きる。

**定義が必要な箇所（PM確認）**：`EVC.sameN`（1行）と `evBored()`（1行）だけ。
1. 何を「飽きたサイン」とみなすか。いまは**仮に「同じ型の場面が2回つづいた」**を置いてある（未決定と明記）。他の候補：同じ場所への再訪、会話を途中でやめた回数、発音の失敗の続き。
2. 仮の定義での動き（ヘッドレスで実測）：順番どおりに通して遊ぶと a・d・e が起き、b・c は起きない（その時点で型が続いていないため）。f・g は機内・メトロでサインしだい。確認用に `?ev=all`（全部起こす）／`?ev=off`（起こさない）を入れた（テスト用。表には出ない）。
3. 1セーブに1回でよいか（2周目に再び起こすか）。
