## 2. 案

**案1「放送で動く」**：会話のあと、場面の中で短い放送や指示が1回流れ、今日の語が2〜3語入る。既存の▶の形（英文だけ・読み上げ）で行き先を2〜3個から選び、動く。間違えても止めず、別のゲートに着いて相手が一言返し、戻る。正誤の印なし。所要15〜25秒。測れるもの：放送後に選ぶまでの間と、行き先が合ったか。弱点：毎場面に置くと同じ型が残る／抽象語（though、anyway、instead 等）は行き先にできない／「聞き取り→選択肢のくり返し」の禁止に近い。

**案2「会話に溶かす」**：別画面を作らない。会話5往復のうち1〜2か所に▶の分かれ目を入れる。相手の一言に今日の語が入り、英文の返事を2〜3個から選んで声に出す。選び方で相手の反応が変わる（ちぐはぐなら聞き返す）。計時は画面に出さず裏で測る。追加時間約8〜16秒。Meaning! は消え、意味は相手の反応で伝える。弱点：台本に分かれ目を足す作業が要る／1か所で2〜3語しか測れず、測れない語は「未測定」のまま。

**案3「画面をなくして迷いだけ拾う」**：Word Battle も Meaning! もなくす。カンペで「おてほん」「もういちど」を押した行の語、ヘルプを使った語、言えなかった語（既存の記録）を持ち越しにする。追加時間0秒、画面も台本も触らない。弱点：測れるのは言うときの迷いだけで、「意味がすぐ出ない」弱点は測れない。選別装置として弱い。

## 3. 選別装置としての卒業と出口（全案共通）

- 語ごとの記録：即答／遅い／間違い／時間切れ（案3は「迷い」）。いま無いのは「即答」と「遅い」。
- 卒業：即答1〜2回で、持ち越し一覧に入れない（回数は未決定の幅）。即答の線は制限の前半（現行なら約2.5秒）が例だが、推測で決めず、まず実データを取る（移行の手順0）。
- 語が1回しか出会わないので、卒業の実質は「持ち越さない」こと。再び出るのは持ち越し先（夢・あとの場面）だけ。

| 起きたこと | 行き先 |
|---|---|
| 即答 | 卒業。何も起きない |
| 遅い | 持ち越し（軽） |
| 間違い・時間切れ | 持ち越し（重） |
| 未測定 | そのまま |

- 009 の save.missed：形は [単語, 発音記号, 意味, 理由] のまま。理由に「遅い」を足す。意味（日本語）は保存だけして画面には出さない。上限16は、夢が5語ずつ受けるなら足りるか要確認。
- 出口（重ねて使える）：①夢（寝る場面で持ち越しの語が夢の会話に入る。夢の中も3択にしない）②あとの場面の看板・一言に混ぜる（バイブル §6）③ルルのひとこと（006 の案B）。
- 夢やあとの場面で自然に通じたら save.missed から外す。通らなければ残す。グアム編は夢のあと夢に出した語が自動で外れる。この違いはグアム編の置き換えで揃える。

## 4. 推奨案と理由

推奨：案2＋夢。
1. 007 A1 を直せる。毎場面の終わりが「テスト→答え合わせ」でなくなり、会話の終わりで区切れる。案1は同じ型の置き換えになるだけ。
2. 006 の B+C の考え方と合う。日常の練習は合否で止めず、実戦は会話の中、受け皿は夢（案F）。
3. 筋トレの前提を守れる。点や×は出ず、計時も画面に出ない。
4. 「意味がすぐ出ない」弱点は口の筋トレに混ぜず、夢とあとの場面で受ける（006 の指摘どおり）。
5. 既存の禁止事項に当たらない（日本語3択なし、文字入力なし、勉強画面なし、「復習」の言葉なし）。
案1は 005 の「飽きたサイン」で入れるイベント（放送で動く）として別枠に回す案。

## 6. キングに決めてほしいこと

1. 方向：案2＋夢でよいか。案1を飽きたサインのイベントに回してよいか。
2. 全問正解まで止まる作りをやめてよいか（006-12 を Word Battle にも当てはめるか）。
3. 会話の分かれ目を1場面に何か所にするか（案2の幅は1〜2か所）。
4. 卒業の回数（即答1〜2回の幅）と即答の線。手順0の実データを取ってから決めてよいか。
5. 夢はグアム編のように、持ち越しが溜まったときだけ見る形でよいか。
6. 数字や表示を、何も見せないか、最後にまとめて見せるか（004-5 に沿う）。
7. カタカナ語（スーツケースなど）は最初から卒業扱いにしてよいか。
