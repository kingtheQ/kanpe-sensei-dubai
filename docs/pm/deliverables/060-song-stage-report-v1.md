## 変更したこと
1. **背景を歌場面版に差し替え**：`nairobi-hotel-lobby-song-v1.png`（1536×960）を新しい art 設定 `nsong` に結び、歌場面（`nbo_song`）だけがこれを使う。通常のロビー（`nlobby`・`nairobi-hotel-lobby-v1.png`・`hall-singer` など）の設定と素材はそのまま（git の blob が変更前と同じことをテストで確認）。
2. **歌手を台の上に**：中心 x=790・足もと y=734（高さ236px。原寸の歌手素材から NEAREST で縮小）。♪は今までどおり歌っているあいだだけ頭の上に出る。
3. **観客5人を半円に**：足もとの中心 (x, y) と高さは、同梱プレビューの実測（マサイは画素が完全一致、ほかは約80%一致）。safari (494, 872) / thobe (584, 898) / backpacker (990, 888) / maasai (1075, 862) / dashiki (1000, 905。プレビューでは手前の2人の陰にほぼ隠れ、見えるのは左はしだけなので、見え方に合わせた推定値)。ルル (708, 948)・キング (844, 948) は観客の中央（既存の `tk-lulu-back` / `tk-king-back` をそのままの大きさで使用）。
4. **入りの改善**：入る→観客が集まった絵＋入りの1行（日本語。絵に合わせて書き直した）→「つぎへ」→ルルが歌手に気づく一言（英語だけ・読み上げ・日本語訳なし）：`Look, King! Someone is going to sing.` →「GO！」で歌が始まる。曲はこれまでどおり「GO！」の操作の中だけで鳴る（自動再生の制限に合う）。
5. **変えていないもの**：歌（song-theme.mp3）・曲後の4行のやりとり・曲の途中の出口・音オフのときの「つぎへ」・保存データ（save.seen など）・ほかの場面（ホテルの部屋・SIM・タクシー・入国審査・荷物・ドーハなど）。

## プレビューと違う点（キングの目で見てほしいところ）
- **歌手の足**：プレビューでは歌手の腰から下が台の手前の板で隠れているが、背景（song-v1）の台とは形が合わない。指示の「足もと y≈734」に従い、**台の上に全身を出した**（足は台の手前のふち）。腰から下を隠したい場合は指示がほしい。
- **thobe の荷物**：同梱の thobe の絵は右手に旅行かばんを持つが、プレビューでは荷物が出ていない。素材はそのまま使い、荷物も出している（ルルの左どなりまで少し出る）。
- 観客の絵は repo の既存 `t-*-back` ではなく同梱のものを使った（プレビューが同梱の絵で作られていたため。マサイで画素一致を確認）。
- 入りの1行（日本語）は、台と観客の絵に合わせて書き直した（旧：「奥のラウンジの隅から、やさしい歌声が…」）。
