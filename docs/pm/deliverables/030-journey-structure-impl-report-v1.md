# 030 旅の骨組みの実装 完了報告 v1（2026-11-18）

土台: `docs/pm/deliverables/020-journey-structure-design-v1.md`。コード: `tour-src/trip.js`（新規。ビルドが tour/・tour/doha/・tour/ending/・world/ に同じものを入れる）。

## 入れた仕組み
- **DAY**: 朝の1枚（"DAY n" と、ルルの英語のひとこと）を開いた回数を数える。休養日（表で rest の日）も1日。29・30日目は DAY を出さず、30日目は "One month later." の1枚から。
- **券の束（つづり）**: 窓口で券を買うと、oneworld 13区間（11枚＋別切符2枚）／スター13区間のつづりを渡す。搭乗ゲート（ナイロビ）と世界マップの飛行でちぎれ、控えは「日・写真・お金の1行」つき。世界マップの「チケットを みる」で見られる。
- **数え方**: 世界マップの「クリア n / 20」をやめた。旅の中は「区間 n / 13」、旅の外は分母なしの「スタンプ n」。
- **記録**: 新キー `kanpe-trip-v1`（日ごとの行＝写真の元の場面名・お金の1行・選んだ乗り物・つづりの状態）。既存の `kanpe-world-v1` `kanpe-pron-v1` `kanpe-voice-v1` `kanpe-tour-save-v1` は読むだけで書き換えない。「はじめから → はい」では `kanpe-trip-v1` も消す。
- **夜の1枚**: その日の場面を遊び終えると自動で出る（寝る場所の選択はなし）。その日の写真がゆっくり浮かび、お金の1行が付く。休養日は朝の1枚のあと、そのまま夜の1枚へ。
- **精算（29日目）とアルバム（30日目）**: ending ページで、ルルが旅のお金の合計・いちばん使った日の写真・メトロで浮いた額を読み上げる → "One month later." → 013の1ページ目 → 2日目から1日1ページ（写真＋控え＋レシートの1行）→ 最後の白いページ。
- **鍵**: その日の場面の場所だけ開く（先の日の場所・タブは閉じる）。到着地にいない日は朝の1枚が開かない（未実装の行き先は地図とつづりに出るが、入れない）。
