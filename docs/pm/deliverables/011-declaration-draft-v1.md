## 0. 結論（先に）

1. **宣言文は70語・9文。** 英語の39音を**39すべて**含む。現行の冒頭で測れなかった V は 0語→7語、TH（θ）は thank のみ→4語。弱点候補の音（F・V・B・TH・語尾のL）は、すべて別々の単語3つ以上に入れた（第1章）。
2. **5本目は会話4（欧州とアフリカ）を推す。** 判断表12行のうち、確定4本で4行、会話4を足すと**6行**をカバー。会話4はケニア・フィンランドと直結する（第2章）。同率の対抗は会話7（南の島とカナダ）。決めるのはキング。

## 1. パート1：宣言文のドラフト

場所：003 のフロー5（旧「夢を言う」）の位置。聞き取りの前、賢者の送り出しの直後。言うのはキング。ルルと二人で旅をする宣言として書いた。

### 1-1. 本文（英語）

> This is my promise, Lulu.
> We will travel around the world together, and have fun every day.
> My body is healthy, my mind is calm.
> I eat good food, sleep well, and never push too hard.
> When I feel afraid, I breathe and think of you.
> We both help each other.
> Let's see every village, hear every voice, and share every little treasure.
> Thank you for being here.
> Let's go!

（改行は読みやすさのため。画面では1枚の紙として続けて見せる想定。004 の共通の形に合わせる。）

### 1-3. 作るときに考えたこと

- 依頼の言葉「心身健康でキングと協力して旅をする」を、**話し手＝キング、協力する相手＝ルル**と読んだ。読み違いならここを直す（確認1）。
- 「心身健康」は第3〜4文（からだ・心）に入れた。健康の助言や診断ではなく、旅への気持ちの宣言にしている。
- 勉強の誓いにしないため、「頑張る」「練習する」「上達する」の語は使っていない。ルルへの呼びかけで始め、「Let's go!」で終わる、声に出して終われる形にした。
- 長さ70語は、毎分100〜120語の計算で約35〜42秒（004と同じ計算。実測ではない）。
- 地名（Kenya など）は入れていない。音声認識が外しやすいことと、004 の方針（地名・名前は数えない）に合わせた。名前は Lulu が1回（文末）だけ。lulu を hello と聞く既知の聞き違いは、既存の「これでOK」の仕組みで合格にできる（プロジェクト指示6章、004 3-5 の9）。

### 2-4. 選定案：**会話4（欧州とアフリカ）**

理由（強い順）：
1. **判断表のカバーが2行（欧州・アフリカ）で、会話7と並んで最大。** 残り6本のうち2行を埋められるのは会話4と会話7だけ。
2. **この2行は、1周目の地図にある場所の行。** キングの地図にはフィンランド（欧州）とケニア（アフリカ）がある。会話4の台詞は「You have Finland in Europe, and Kenya in Africa.」で始まる。会話7の2行（南太平洋・カナダ）は、タヒチもカナダも1周目の地図にない。初回の体験として、自分の置いたピンの話の方が記憶に残る。
3. **賢者の言葉と流れがつながる。** 会話4の4往復目の「欧州に戻る？戻れないと思っていました」は、賢者の第1の台詞「引き返せません」（003 第3章）への答えになっている。決まりを「止められた経験」で入れる設計の要。
4. **初回の流れを壊さない。** 初回5本（会話1・2・4・5・8）の英語の語数は合計558（会話7にした場合は534、差24語）。会話4は124語で、確定4本の最長（会話1＝118語）より6語長い。▶は5本で6か所。

**注意（実装前に見てほしい点）：**
- 会話4は6本の中で▶が最多（2か所）。初回5本で▶が計6か所になる。重さを抑えたいなら、2往復目の▶を固定の台詞にして▶を1か所にする手がある（その場合、判断表の「欧州」の行は印がつかない）。
- 会話4の選択肢Bは「たくさんの欧州の街」「もっとアフリカ」で、1周目の固定の地図（4か所）と食い違う。選んだとき係員が「地図に足す」のか「次の旅のメモ」（003-12）に残すのか、台本で決める必要がある。
- 1周目の基本の結果（003 2-3：会話2でA＝oneworld Explorer、会話5でA＝スター、同点でキングが決める）は、会話4の自然な答え（地図どおりの A・A）なら印が増えず変わらない。B・B を選ぶとスターに印が2つ増える。003 の文を読んだ上での整理で、実機の画面はまだない。

## 付録：数え方の道具（そのまま動く）

`pip install cmudict` のうえで、文字列を標準入力かファイルで渡す（`python3 -I snd.py 文.txt`）。読みが複数ある語は cmudict の第1候補（ipa.py と同じ）。read だけ手で指定。

```python
import re, sys, json
import cmudict
D = cmudict.dict()
# 同じつづりで読みが2つある語の手指定（004と同じ方針）
OVR = {'read':['R','IY1','D']}
NAMES = {'lulu','kenya','finland','peru','hawaii','haneda','nairobi'}

assert len(ALL39)==39

def words(t):
    return [w for w in re.findall(r"[a-zA-Z']+", t.replace('’',"'"))]
def pron(w):
    w=w.lower()
    if w in OVR: return OVR[w]
    if w not in D: return None
    return list(D[w][0])
def base(p): return re.sub(r'\d','',p)
def tags(w):
    ph = pron(w)
    if ph is None: return None
    b=[base(p) for p in ph]; st=[re.sub(r'\D','',p) for p in ph]
    t=set()
    for i,p in enumerate(b):
        nxt = b[i+1] if i+1<len(b) else None
        if p=='TH': t.add('θ')
        if p=='DH': t.add('ð')
        if p=='F': t.add('F')
        if p=='V': t.add('V')
        if p=='B': t.add('B')
        if p=='R' and nxt in V: t.add('R')
        if p=='W': t.add('W')
        if p=='SH': t.add('SH')
        if p=='NG': t.add('NG')
        if p=='AE': t.add('æ')

        if p=='ER': t.add('ɚ')
        if p=='IH': t.add('ɪ')
        if p=='UH': t.add('ʊ')
        if p=='L':
            if nxt in V: t.add('L前')
            else: t.add('L尾')
        if p=='S' and nxt in ('IY','IH'): t.add('S+イ')
    # 短母音+有声語尾
    if len(b)>=2 and b[-2] in ('IH','EH','AE','AH','UH') and b[-1] in ('B','D','G','V','Z','JH','DH'): t.add('短V+有声尾')

    # 子音連続
    run=0
    for p in b:

            run+=1
            if run>=2: t.add('C連続');
```
