# カンペ先生 ドバイ編

ドバイ空港で話す英会話のリハーサルゲーム(試作・私用)。音声は保存も送信もしません。発音の記録は、各自のブラウザ(localStorage)にだけ残ります。

## 同じ場所に置いている別の版

- `guam/` : カンペ先生 グアム編(時計版)。公開後は `/guam/` で開く。20空港の現地時刻と日本時間を時計に表示する。天気は Open-Meteo(個人情報なし)から取得し、取れないときは月ごとの平均で表示する。

## 発音記号について

強化合宿の発音記号は、CMU Pronouncing Dictionary(米国英語の公開辞書)から、このゲームの会話に出る単語分を作って埋め込んでいます。
